# 1. 本阶段目标与最终数据流

## 1.1 目标

本阶段只负责构建**路径条件下的点级安全椭圆监督数据集**。

输入：

-   Moving AI 格式的二维占据地图；
-   机器人等效半径；
-   随机生成的起点和终点。

输出：

-   A\* 搜索路径；
-   路径稀疏采样点；
-   每个采样点对应的 128×128 局部膨胀占据地图；
-   每个采样点对应的 16 条测距射线；
-   通过离线几何优化生成的安全椭圆监督标签；
-   按地图或地图组划分的训练、验证、测试数据集；
-   数据生成统计报告和可视化样例。

本阶段不实现神经网络，也不训练网络。数据集字段应与后续网络输入/输出接口对齐，但不要提前实现模型。

## 1.2 核心思路

每条搜索路径被稀疏采样为一系列路径点。每个路径点单独生成一个训练样本。

对于路径点 (p_i)：

1.  裁剪以该点为中心的局部占据地图；
2.  从该点向 16 个方向发射测距射线；
3.  根据射线测距结果生成多个候选偏置中心；
4.  对每个候选中心运行固定中心的 IRIS 风格几何求解；
5.  只保留同时满足"椭圆安全"和"路径点位于椭圆内部"的候选；
6.  选择得分最高的候选作为监督标签。

整体流程：

``` text
Moving AI maps
    ↓
Map parsing
    ↓
Robot-footprint inflation
    ↓
Random start/goal sampling
    ↓
A* path search
    ↓
Arc-length path sampling
    ↓
128×128 local occupancy patch
    +
16 sparse range rays
    ↓
Ray-based candidate center generation
    ↓
Fixed-center IRIS-style ellipse optimization
    ↓
Path-point inclusion + full ellipse safety validation
    ↓
Sample filtering and map-group split
    ↓
train / val / test NPZ
```

# 3. 地图数据处理

## 3.1 `.map` 文件读取

参考 Neural-IRIS 的 `load_moving_ai_map()`，但应完善异常检查。

解析：

-   `height`；
-   `width`；
-   `map` 起始行；
-   后续对应数量的地图字符行。

统一转换成二维 `uint8` 占据矩阵：

``` text
0：自由栅格
1：障碍栅格
```

Moving AI 常见障碍字符按 Neural-IRIS 当前实现处理：

``` text
@、O、T、W → 障碍物
```

其余有效地图字符按自由区域处理。遇到未知字符、行长度与 width
不一致、地图行数与 height
不一致时，应记录文件名并报出明确错误，不能静默截断。

每张地图生成一条元信息记录：

-   文件名和相对路径；
-   width、height；
-   分辨率；
-   自由栅格数量；
-   障碍栅格数量；
-   障碍占比；
-   地图是否成功解析。

地图文件名中的 256、512、1024 等数字不能代替实际 header 尺寸。

## 3.2 地图分辨率

本数据集默认：

\[ r\_{`\mathrm{map}`{=tex}}=0.25 `\mathrm{m/cell}`{=tex} \]

即一个栅格代表 0.25 m。

如果 `.map`
文件没有物理分辨率字段，使用配置文件中的默认值。不要根据地图文件名推测分辨率。

## 3.3 机器人尺寸与障碍物膨胀

机器人等效半径：

\[ r\_{`\mathrm{robot}`{=tex}}=0.25 `\mathrm `{=tex}m \]

对应：

\[ r\_{`\mathrm{cell}`{=tex}}=
`\frac{r_{\mathrm{robot}}}{r_{\mathrm{map}}}`{=tex}=1 \]

第一版沿用 Neural-IRIS 的离散处理约定：

-   使用 3×3 全 1 结构元素；
-   对障碍物二值图膨胀一次；
-   膨胀后的占据图作为机器人中心的规划地图。

这是一种偏保守的栅格近似，方形膨胀在对角方向比半径 0.25 m
的圆形模型更保守。第一版统一采用该约定，避免搜索、射线和椭圆标签使用不同的机器人模型。

生成：

-   `occupancy_raw`：原始地图；
-   `occupancy_inflated`：膨胀地图。

\*\*后续
A\*、局部地图输入、射线测距、椭圆标签生成和最终安全性验证，全部使用同一份
`occupancy_inflated`。\*\*

不要在不同阶段重复膨胀。膨胀后的地图缓存应记录膨胀参数，避免重复处理。

地图边界外视为障碍物。局部地图裁剪超出原图的区域也必须填充为障碍物。

## 3.4 距离变换

在膨胀地图上计算到最近障碍栅格的欧氏距离变换，单位先保留为
cell，必要时乘以 0.25 转为米。

距离变换主要用于：

-   起终点有效性检查；
-   路径局部净空统计；
-   路径样本分层；
-   可视化和质量报告。

不要将距离变换直接当作安全椭圆标签。椭圆标签仍由后面的几何优化生成。

# 4. 起终点采样与 A\* 路径生成

## 4.1 搜索地图

只在 `occupancy_inflated` 上搜索。

起点和终点必须满足：

``` text
occupancy_inflated[y, x] == 0
```

并且不能位于地图边界填充区域。

## 4.2 A\* 搜索

使用二维 8 邻域 A\*：

-   水平、竖直移动代价为 1；
-   对角移动代价为 (`\sqrt{2}`{=tex})；
-   使用欧氏距离作为启发函数；
-   禁止对角穿角：对角移动时，两个相邻正交栅格必须均为自由栅格。

搜索输出：

``` text
path = [(x0,y0), (x1,y1), ..., (xn,yn)]
```

坐标统一使用 `(x, y)`，即 `(列, 行)`，不能在不同模块之间交换 x、y。

A\* 路径是离散引导路径，不需要在本阶段做 B 样条平滑。

## 4.3 起终点采样

每张地图随机生成多组起终点。

初始建议参数：

  参数                                     默认值
  ---------------------------- ------------------
  每张地图目标有效路径数                      100
  每张地图最大起终点尝试次数                  500
  起终点最小欧氏距离              32 cells（8 m）
  最短有效路径长度               40 cells（10 m）
  随机种子                             42，可配置

以上参数必须放入 YAML 配置文件，不能散落在代码中。

采样时注意：

-   起点、终点不能落在障碍物中；
-   不允许起终点相同；
-   搜索失败的路径不保存；
-   路径长度不足的路径不保存；
-   避免反复生成完全相同或高度重合的起终点对；
-   对不同地图、不同路径使用可复现的独立随机种子。

每条路径保存：

-   map_id；
-   path_id；
-   start、goal；
-   完整栅格路径；
-   路径长度；
-   起终点直线距离；
-   路径曲折度；
-   路径点局部净空统计。

## 4.4 路径多样性

不能只生成开阔区域内的简单直线路径。

至少统计并覆盖：

1.  开阔区域路径；
2.  普通障碍环境路径；
3.  多次转弯路径；
4.  狭窄通道路径；
5.  障碍物边缘附近的路径。

建议按路径点到最近膨胀障碍物的距离，将样本划分为：

  类别       到最近障碍物的距离
  ---------- --------------------
  紧凑空间   1--3 cells
  中等空间   3--8 cells
  开阔空间   大于 8 cells

这是样本统计和均衡采样的分层标准，不是额外的障碍膨胀距离。

如果某张地图无法产生足够的紧凑空间路径，应在报告中记录，不要人为伪造路径。

# 5. 路径稀疏采样

## 5.1 采样目的

一条 A\*
路径可能包含大量相邻栅格点，不能把所有栅格都当成独立训练样本，否则会产生大量高度相似的数据。

需要沿路径弧长进行稀疏采样，同时保留转弯位置。

## 5.2 默认采样间距

初始采用：

\[
d\_{`\mathrm{sample}`{=tex}}=4 `\mathrm{cells}`{=tex}=1.0 `\mathrm `{=tex}m
\]

实施要求：

-   按累计路径弧长等间距采样；
-   保留明显转弯位置；
-   当相邻路径段方向变化超过 30° 时，将对应转弯点加入采样候选；
-   对距离小于 2 cells 的重复样本进行去重；
-   对路径起点和终点可以保留样本，但必须保证其局部地图裁剪有效。

最终采样点保留原始地图坐标、所属路径编号和沿路径的顺序编号。

## 5.3 路径切向

每个采样点计算局部路径切向：

\[ t_i=`\frac{p_{i+1}-p_{i-1}}`{=tex}
{\|p\_{i+1}-p\_{i-1}\|\_2+`\epsilon`{=tex}} \]

端点使用单侧差分。

保存：

``` text
path_tangent = (tx, ty)
```

第一版射线角度仍然相对于地图全局坐标系，不对局部地图做旋转。路径切向作为辅助元数据保存，供后续网络或数据分析使用。

# 6. 局部地图与测距射线特征

## 6.1 局部地图裁剪

每个路径点裁剪一个 128×128 的局部地图：

\[ M_i`\in`{=tex}{0,1}\^{128`\times128`{=tex}} \]

路径点固定对应局部坐标：

\[ p_i\^{local}=(64,64) \]

局部地图物理尺寸：

\[ 128`\times0.25`{=tex}=32 `\mathrm `{=tex}m \]

即 32 m × 32 m。

裁剪范围超出原始地图时，越界区域填充为障碍物。

网络输入使用**膨胀后的局部占据地图**，因为后续椭圆标签也是基于膨胀地图生成的。

同时可以保留原始局部地图用于可视化，但不要把原始地图和膨胀地图混淆。

## 6.2 16 条测距射线

第一版使用：

\[ N\_{`\mathrm{ray}`{=tex}}=16 \]

射线方向：

\[ `\theta`{=tex}\_k=`\frac{2\pi k}{16}`{=tex},
`\quad `{=tex}k=0,`\ldots`{=tex},15 \]

以局部路径点 `(64,64)` 为原点，沿地图全局坐标系发射射线。

最大测距范围：

\[ d\_{`\max`{=tex}}=64 `\mathrm{cells}`{=tex}=16 `\mathrm `{=tex}m \]

测距必须在膨胀地图上进行。

射线遇到以下情况时停止：

-   第一个障碍栅格；
-   局部地图边界；
-   最大测距距离。

建议使用 supercover / 栅格遍历方式，避免对角射线跳过细小障碍物。

每条射线保存：

-   `ray_distance`：测得距离，单位统一为 cell 或
    m，数据集中只能选择一种并保持一致；
-   `ray_hit`：是否在量程内命中障碍物。

建议最终存储归一化距离：

\[ `\hat `{=tex}d_k=`\frac{\min(d_k,d_{\max})}{d_{\max}}`{=tex} \]

没有命中障碍物时：

``` text
ray_hit = 0
ray_distance = 1.0
```

命中障碍物时：

``` text
ray_hit = 1
ray_distance = 实际距离 / 最大测距距离
```

同时保存未归一化的物理距离，便于调试。

# 7. 射线候选偏置中心生成

这是本项目区别于 Neural-IRIS 的重要部分。

Neural-IRIS 直接以随机锚点作为 IRIS
初始位置。本项目要利用搜索路径点和测距射线生成多个候选椭圆中心。

## 7.1 候选中心定义

路径点为 (p_i)，第 (k) 条射线单位方向为：

\[ u_k=
```{=tex}
\begin{bmatrix}
\cos\theta_k\\
\sin\theta_k
\end{bmatrix}
```
\]

射线测得的自由距离为 (d\_{ik})。

候选中心：

\[ c\_{ikj}=p_i+`\lambda`{=tex}*jd*{ik}\^{safe}u_k \]

其中偏置比例初始设置：

\[ `\lambda`{=tex}\_j`\in`{=tex}{0.25,0.50,0.75} \]

另外始终保留一个不偏置候选：

\[ c\_{i,0}=p_i \]

`d_safe`
是扣除边界数值余量后的可用距离。射线命中障碍物时，候选中心不能越过第一个障碍物；没有命中时，也不能超过最大测距范围。

## 7.2 候选中心安全检查

每个候选中心必须通过：

1.  位于局部地图范围内；
2.  位于膨胀地图自由区域；
3.  从原路径点到候选中心的整条线段均位于自由空间；
4.  不位于障碍物栅格边界的数值不确定区域。

线段检查必须采用栅格 supercover 检查，不能只检查候选中心终点。

若候选不满足要求，直接丢弃。

## 7.3 候选去重

不同射线和偏置比例可能产生非常接近的候选中心。

对空间距离小于 1 cell
的候选进行去重，保留偏置比例较小或测距更可靠的候选。

不偏置候选必须始终保留。

## 7.4 偏置类别标签

定义：

``` text
0～15：对应 16 条射线方向
16：不偏置
```

对于不偏置候选：

``` text
offset_direction = 16
offset_ratio = 0
```

对于偏置候选：

``` text
offset_direction = ray_index
offset_ratio = lambda
```

最终训练标签中的偏置比例为相对于该射线可用距离的比例，不是固定的米数。

# 8. 离线安全椭圆监督标签生成

## 8.1 核心要求

每个候选中心对应一个候选椭圆。

最终椭圆必须同时满足：

**要求 A：椭圆中心处于膨胀地图自由空间。**

候选中心在进入椭圆优化之前已经经过自由空间检查。

**要求 B：整个椭圆位于无障碍自由区域。**

不能只检查椭圆中心或椭圆边界的少量点。

**要求 C：原始搜索路径点必须处于椭圆内部。**

设路径点为 (p_i)，椭圆中心为 (c_i)，椭圆半轴为 (a_i,b_i)，方向角为
(`\phi`{=tex}\_i)，则：

\[ q_i=R(`\phi`{=tex}\_i)\^T(p_i-c_i) \]

要求：

\[ `\left`{=tex}(`\frac{q_{i,x}}{a_i}`{=tex}`\right`{=tex})\^2+
`\left`{=tex}(`\frac{q_{i,y}}{b_i}`{=tex}`\right`{=tex})\^2
`\leq `{=tex}`\eta`{=tex}\^2 \]

初始取：

\[ `\eta=0.9`{=tex} \]

该条件比简单的椭圆内部约束更严格，为路径点留出一定内部余量。

## 8.2 椭圆参数约定

采用中心和对称正定形状矩阵表示：

\[ `\mathcal `{=tex}E(c,L)=
{x`\mid `{=tex}x=c+Lz, \|z\|\_2`\leq1`{=tex}} \]

其中：

-   (c)：椭圆中心；
-   (L)：对称正定矩阵；
-   \(L\) 的两个特征值对应两个半轴长度；
-   特征向量对应椭圆主轴方向。

注意：Neural-IRIS
的离线求解器返回的是椭圆形状矩阵，其运行时几何代码使用半轴倒数构建二次型矩阵。实现时必须区分"形状矩阵"和"二次型矩阵"，不能把两者混用。

## 8.3 固定中心最大体积椭圆

**必须修改 Neural-IRIS 求解器的优化变量设置。**

Neural-IRIS 当前 `solve_iris_offline()`
中，椭圆形状矩阵和中心都是优化变量。本项目的中心已经由射线候选生成，因此求解阶段必须固定候选中心
(c)，只优化椭圆形状矩阵。

沿用 IRIS 风格：

1.  从膨胀地图提取障碍物边界点；
2.  根据当前候选椭圆和障碍物点构造分离超平面；
3.  加入局部地图四周边界约束；
4.  求解固定中心的最大体积椭圆；
5.  更新活动障碍物约束，迭代至收敛或达到最大迭代次数。

对于安全凸多面体：

\[ `\mathcal `{=tex}P={x`\mid `{=tex}Ax`\leq `{=tex}b} \]

固定中心 (c) 的椭圆约束为：

\[ a_j^Tc+\|L^Ta_j\|\_2`\leq `{=tex}b_j \]

目标：

\[ `\max`{=tex}\_{L`\succ0`{=tex}}`\log`{=tex}`\det `{=tex}L \]

这与 Neural-IRIS 的最大体积椭圆求解思路一致，但不再优化中心变量。

求解器优先使用 CLARABEL，失败时允许使用 SCS
作为备用。记录求解状态、迭代次数和耗时。

建议初始参数：

  参数                              默认值
  ------------------- --------------------
  IRIS 最大迭代次数                     20
  角度分桶数量                          32
  收敛体积变化阈值                      5%
  最小特征值            正数，设置数值下限
  求解器                CLARABEL，SCS 备用

不要因为求解器返回 `optimal_inaccurate`
就直接认定标签有效，必须继续进行后面的几何验收。

## 8.4 路径点包含性检查

得到固定中心椭圆后，计算：

\[ `\rho`{=tex}\_i= `\left`{=tex}\|L\^{-1}(p_i-c)`\right`{=tex}\|\_2 \]

接受条件：

\[ `\rho`{=tex}\_i`\leq0.9`{=tex} \]

如果不满足，说明该候选椭圆不能容纳原始路径点，直接丢弃该候选。

不要通过移动椭圆中心来强行满足路径点包含条件，因为这会破坏"候选偏置中心由射线选择"的监督语义。

注意：不偏置候选 (c=p_i)
时，路径点位于椭圆中心，理论上自动满足包含条件。若不偏置候选也失败，应检查几何求解器是否退化或返回了无效矩阵。

## 8.5 整个椭圆的安全性检查

必须对完整椭圆进行安全性验证。

不能只采用 Neural-IRIS 当前数据生成代码中的 48
个边界点加随机内部点抽样作为最终安全性证明。

推荐实现：

1.  先根据椭圆参数计算其局部包围盒；
2.  找出包围盒内所有膨胀障碍栅格；
3.  检查每个障碍栅格对应的方形区域是否与椭圆相交；
4.  只要存在相交，当前候选就判定为不安全。

二维椭圆与轴对齐栅格方形的相交检查，可以通过最小化椭圆二次型在该方形区域内的值实现。二次型在矩形上的最小值可通过内部解、四条边上的一维最小值及边界端点计算。

判断条件：

\[ `\min`{=tex}\_{x`\in`{=tex}`\mathrm{cell}`{=tex}}
(x-c)^T(LL^T)\^{-1}(x-c)`\leq1`{=tex} \]

如果满足，则该栅格与椭圆相交，候选不合格。

若第一版暂时采用栅格超采样作为加速近似，必须增加保守边界余量，并在最终报告中明确它是近似验收，不能宣称为严格的连续几何证明。

## 8.6 候选椭圆选择

对一个路径点，可能有多个候选中心和对应椭圆。

只有通过以下全部检查的候选才参与比较：

-   候选中心自由空间检查；
-   线段自由空间检查；
-   椭圆矩阵正定；
-   求解器状态有效；
-   路径点包含性检查；
-   完整椭圆安全性检查；
-   椭圆尺寸不退化。

候选评分建议：

\[ J=`\log`{=tex}`\det `{=tex}L-`\mu`{=tex}`\lambda`{=tex}\^2 \]

其中：

-   第一项鼓励较大的椭圆；
-   第二项适当抑制没有必要的过度偏置；
-   初始 (`\mu=0.05`{=tex})，放入配置文件，后续可做敏感性检查。

选择得分最高者作为该路径点的监督标签。

若得分接近，优先选择偏置比例较小的候选；若仍然相同，按射线编号确定性选择，保证数据生成可复现。

如果所有偏置候选都失败，仍然尝试不偏置候选。只有不偏置候选也失败，才将该路径点标记为无有效标签。

# 9. 标签参数与数据格式

## 9.1 标签定义

  -------------------------------------------------------------------------------------------------------
  字段                      类型                    含义
  ------------------------- ----------------------- -----------------------------------------------------
  `offset_direction`        int64                   0--15 对应射线，16 表示不偏置

  `offset_ratio`            float32                 偏置比例

  `ellipse_ab`              float32\[2\]            长、短半轴，单位 m

  `ellipse_angle`           float32\[2\]            (`\sin`{=tex}`\phi`{=tex},`\cos`{=tex}`\phi`{=tex})

  `ellipse_area`            float32                 椭圆面积，单位 m²

  `point_inside_metric`     float32                 路径点椭圆归一化距离 (`\rho`{=tex})

\[ a`\geq `{=tex}b\>0 \]

(`\pi`{=tex}) 的标签。

`angle_valid=0`，后续训练时可屏蔽该样本的方向角损失。

# 10. 数据筛选与数据集划分

## 10.1 样本过滤

过滤规则：

1.  地图解析有效；
2.  路径点处于膨胀自由空间；
3.  局部地图有效；
4.  射线特征有效；
5.  椭圆中心位于自由区域；
6.  椭圆形状矩阵正定；
7.  椭圆半轴大于设定的最小值；
8.  路径点满足内部包含条件；
9.  完整椭圆没有与膨胀障碍物相交；
10. 所有标签数值均为有限值，不包含 NaN 或 Inf。

每个失败样本记录原因，例如：

``` text
invalid_start_or_goal
astar_failed
patch_invalid
candidate_center_occupied
candidate_segment_collision
iris_solver_failed
ellipse_degenerate
path_point_outside_ellipse
ellipse_collision
```

不能只记录最终保留样本数，否则无法判断数据质量问题来自哪里。

## 10.2 数据集划分

优先按照地图或地图组划分：

``` text
train：80%
val：10%
test：10%
```

划分前先建立地图组 ID。对于文件名中存在 `_part_`
的地图，至少应将同一母地图的不同 part
归为同一组，避免相邻地图块分别进入训练集和测试集。必要时允许通过配置文件显式指定地图组。

**不能直接照搬 Neural-IRIS 的随机样本级 8:1:1 划分。**

如果实际只有三张独立地图：

-   可以先采用按路径分组的开发集划分；
-   同一条路径的样本必须进入同一个 split；
-   报告中必须注明这是同地图分布内测试；
-   不能将该结果解释为跨地图泛化能力。

当地图数量足够时，再启用严格地图组级划分。

固定随机种子并将地图组划分结果保存为独立文件。后续重新生成数据集时必须复用该划分，避免训练集和测试集地图发生变化。

# 14. 关键实现注意事项

以下问题必须特别注意：

### 14.1 不要把路径点和椭圆中心混为一谈

路径点是网络需要覆盖的引导点；椭圆中心是网络根据局部空间选择的偏置位置。两者可以不同，但路径点必须位于椭圆内部。

### 14.2 不要直接复用 Neural-IRIS 的自由中心求解器

当前 Neural-IRIS 的 `solve_iris_offline()`
会更新椭圆中心。本项目必须固定候选中心，只优化椭圆形状，否则射线偏置标签就失去意义。

### 14.3 不要只检查椭圆中心

椭圆中心位于自由空间，不代表整个椭圆安全。必须检查整个椭圆与膨胀障碍物的关系。

### 14.4 不要只检查路径点在椭圆边界以内

必须使用严格的内部包含指标，默认 (`\rho`{=tex}`\leq0.9`{=tex})。

### 14.5 不要在不同阶段使用不同地图

A\*、射线、椭圆优化、最终碰撞检查必须统一使用同一张膨胀地图。

### 14.6 不要随机打散所有点后划分数据集

同一路径上的相邻点高度相似，必须按地图组或路径组划分。

### 14.7 不要为了增加样本数量放宽安全条件

如果有效样本数量不足，应先分析候选中心、射线测距、路径分布和椭圆优化失败原因，而不是直接降低安全性验收标准。
