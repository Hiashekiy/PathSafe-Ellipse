# PathSafe-Ellipse V2.1 实施与实验记录

对照 `PathSafe-Ellipse_V2.1_拓扑约束净空中心线优化改造方案.md`。**只改中心线模块**，
A*、椭圆生成器（`v2/ellipse.py`）、场景采样（`v2/scene.py`）未改动；V2 的代码路径与数据保留。

## 1. 实现

| 方案条目 | 实现 |
|---|---|
| §2.2 路线约束域 | 每站半径 `R_i = min(R_max, 0.45·d_i^nonlocal)`（可配置 `nonlocal_min_index_gap`）；切向限制 `\|t_i·(q_i−p_i)\| ≤ η·L_i`（η=0.25）；端点固定；`D(q_i) ≥ d_safe = 0.25+0.04+0.01 = 0.30 m` |
| §3.1 目标函数 | `min −w_D·Σω_i·min(D(q_i),6)/6 + w_s·Σω_i·L_ref²\|a_i\|² + w_p·Σω_i\|q_i−p_i\|²/(R_i²+ε)`，`ω_i` 为弧长权重，`a_i` 为**非均匀弧长**二阶差分；权重 1.0 / 0.15 / 0.02 |
| §3.2 求解 | SLSQP（解析雅可比，约束显式），`max_iter 600, ftol 1e-9`；3 个确定性初值（A*、0.5 m、1.0 m 沿 ±∇D 侧向偏置），每个初值先投影进约束域，取目标最优者 |
| §4.1 验证 | 节点自由、线段自由（0.25 cell 密集采样）、端点固定、偏移合法、切向合法、站序单调、**P→Q 同伦**（λ 采样步长 0.25 cell） |
| §4.3 修复 | 用**单次扫描求最大可行 λ**替代反复 α 二分：接受 `P_{λmax}`，状态记 `blend_x` / `topology_limited` / `fallback_astar` |
| §5.3 锚点 | `anchor_indices()` 改用中心线自身的切向与曲率（此前误用了 A* 切向） |
| §7 记录 | `centerline_method / clearance_gain / length_ratio / homotopy_verified / status / solver_iterations / solver_time_ms` 及全部检查项写入路径记录与场景统计；`label_version = v2.1` |

补充的两处工程修正（诊断驱动，非改动算法思想）：

1. **线段配点约束**：只约束节点会让两个"各自安全"的节点之间切角。增加每段 1/3、2/3 处的
   `D ≥ d_safe` 约束。
2. **`Scene.is_free` 口径统一**：改用连续距离场 `D(x) > r_robot+margin`（与优化器约束一致）。
   原来按最近栅格中心判定，会把可行中心线误判为碰撞并整条回退 A*。
3. **非局部保护的最小站距**：`|j−i| > 1` 会把"同一走廊拐弯"当成不同路段，诊断显示
   `R_i` 均值只有 0.57 m；改为可配置 `nonlocal_min_index_gap: 4`（方案允许"用诊断数据调整"）。
