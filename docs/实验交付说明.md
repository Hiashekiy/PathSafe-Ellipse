## 2. 独立复验结论（关键证据）

`scripts/validate_dataset.py` 完全**不信任生成过程**：从 NPZ 里的 `(a, b, sin φ, cos φ, 中心偏移)`
重建 `L`，对**存储的 patch** 重新做连续几何判定，并重新投射 16 条射线。

每个 split 随机抽 4000 个样本：

| split | 椭圆与膨胀障碍无交集 | 路径点 ρ ≤ 0.9 | 半轴在允许范围 | 最小障碍二次型 | 射线重投偏差 |
|---|---|---|---|---|---|
| train | 4000/4000 | 4000/4000 | 4000/4000 | 1.000712 | 0.0 |
| val | 4000/4000 | 4000/4000 | 4000/4000 | 1.000712 | 0.0 |
| test | 4000/4000 | 4000/4000 | 4000/4000 | 1.000712 | 0.0 |

* 最小障碍二次型 > 1 ⇒ 椭圆与 bbox 内每个膨胀障碍栅格方形**严格不相交**（连续判定，非采样近似）。
* 射线偏差 0.0 ⇒ 输入特征与 patch 严格自洽。
* 划分泄漏检查：无地图组跨 split、无路径跨 split（train/val/test 组互不相交）。

## 4. 训练与测试（实测结果）

模型：`EllipseNet`（0.95 M 参数；5 级 stride-2 卷积 + 射线/切向 MLP 融合；输出中心偏移、
log 半轴、方向正弦余弦、`angle_valid` 逻辑值）。
训练：AdamW + OneCycle，batch 256，lr 2e-3，40 epoch，单卡 RTX 4070，约 22 分钟。
最优 checkpoint 按验证集复合损失选择（epoch 20）。

| 指标 | test（3 个未见地图组，33490 样本） | val（3 个未见地图组，31567 样本） |
|---|---|---|
| 复合损失 | 0.4080 | 0.4428 |
| 椭圆中心偏移误差 | 1.205 m | 1.314 m |
| 半轴 a / b 误差 | 1.089 / 0.617 m | 1.191 / 0.550 m |
| 方向误差（angle_valid 样本） | 15.96° | 14.9° |
| 椭圆 IoU（patch 栅格化） | **0.7684** | 0.7401 |
| 路径点落入预测椭圆（ρ ≤ 0.9） | 0.9673 | 0.9716 |
| 预测椭圆无碰撞 | 0.7202（复验 4000 例） | 0.6927 |
| **安全且包含路径点** | **0.6915** | 0.6697 |

产物：`reports/test_metrics.json`、`reports/training_history.json`、
`reports/training_curves.png`、`reports/test_predictions.png`、
`outputs/checkpoints/ellipse_net_best.pt`。

解读：网络能较好复现"给定局部占据图应取的安全椭圆"（IoU 0.77，路径点包含率 0.97），
但**预测椭圆本身不保证无碰撞**（0.72）——这是纯回归基线的固有局限，也是后续阶段
（安全后校验 / IoU-aware 损失 / B 样条走廊拼接）需要解决的问题。

## 5. 已知限制与后续工作

1. **标签窗口饱和**：椭圆上限受 128×128 patch 窗口（32 m × 32 m）约束，开阔区标签集中在
   15.9 m 半轴附近。窗口外没有观测，不能声明安全；后续可考虑多尺度 patch 或
   "窗口边界不视为障碍 + 置信度标记"。
2. **紧凑空间样本偏少**：净空 1–3 cells 的样本仅约 2.7%（地图本身以街道/广场为主），
   报告已给出分子/分母，未人为伪造。
3. **偏置比例 0.75 从未成为最优**：路径点包含性（ρ ≤ 0.9）在大偏置下难以满足，说明
   0.25/0.5 足够；如需更多多样性可放宽 ρ 或引入路径点加权。
4. **IRIS 收敛标记**：`ellipse_converged=1` 表示椭圆不含任何**膨胀后**障碍角点（保守判据），
   因此约 73% 样本标记为 0，但它们仍通过严格的连续几何安全验收。
5. **求解器替代**：生产路径使用自研 3 变量 log-barrier（与 CLARABEL 解一致到 1e-3），
   CLARABEL/SCS 作为回退与复验通道（本次运行 CLARABEL 回退 0 次）。
6. 网络指标仍有提升空间：预测椭圆无碰撞率 0.72、IoU 0.77 属于纯回归基线水平。
   下一阶段建议：椭圆栅格化 IoU 损失、对"碰撞"样本加权、更大感受野（或双 patch 输入）、
   以及把预测椭圆交给确定性后校验（IRIS/收缩）后再拼接走廊。
