## 3. 与验收标准的差距（必须记录）

| 项 | 目标 | 实测 | 说明 |

| 单椭圆求解+验证耗时 p50 | ≤ 20 ms | **79 ms（跨场景中位数）** | 未达标。分解：3×3 barrier ≈ 7–9 ms，其余为活动集构建 + 多轮精确验证（密集场景 bbox 大）。按文档 §4.6.3 的下一步是"3 变量标量版专用求解器 + 更窄的活动集查询" |
