## 第一阶段：五类典型几何场景验收

合成布局：256×256 @ 0.25 m/格（64 m 视野），每类固定起终点，V2 与 V2.1 用**同一条 A\* 路径**。

| 场景 | 路径长 | V2 净空增益 | **V2.1 增益** | V2 面积 p50 | **V2.1 面积 p50** | V2.1 <5 m² | 触及 R_i 上限 | 同伦 | V2.1 求解 |
|---|---|---|---|---|---|---|---|---|---|
| 一侧靠墙另一侧开阔 | 52.0 m | +0.74 m | **+2.09 m** | 17.47 m² | **57.88 m² (×3.3)** | 0/29 | 35 | ✔ | 883 ms |

（每张含占据图+V2、占据图+V2.1、净空曲线、归一化弧长上的偏移与面积配对曲线、指标表），

解读：

* **开阔侧收益巨大**：一侧靠墙场景净空 2.12 → 3.47 m，面积 ×3.3，且 0 个 <5 m² 锚点。
* **窄通道几何受限**：1.25 m 宽通道内 A\* 已在中间，无增益可拿；V2.1 不破坏任何标签（0.65 m² 与该处几何一致）。
* **S 形通道出现轻微回退**（0.39 → 0.34 m²，−13 %）：粗结点插值 + 投影后中心线略有偏移。已如实记录，未隐藏。
* 直角/U 形：面积提升（0.40→0.66、0.41→0.65），说明"拐角处向内侧敞开空间移动"是有效的。

### 审计 A：同伦验证是否真的覆盖整个 P→Q 变形

单次离散扫描不等于连续证明，因此用**更细的网格复核**（λ 步长 0.25 → **0.02 cell**，即 12.5×；线段采样 0.25 → **0.05 cell**，即 5×），并检查可行域结构：

| 场景 | 生产扫描 (λ 步/线段步) | 复核扫描 | λ_max（生产/复核） | 漏检风险 | 可行区间数 | 单调前缀 | 最小净空裕度 |
|---|---|---|---|---|---|---|---|
| 一侧靠墙 | 46 态 @0.062 m | 564 态 @0.013 m | 1.00 / 1.00 | 否 | 1 | 是 | +1.08 m |
| 窄通道 | 2 态 | 2 态（无位移） | 1.00 / 1.00 | 否 | 1 | 是 | +0.27 m |
| S 形 | 11 态 | 117 态 | 1.00 / 1.00 | 否 | 1 | 是 | **+0.01 m** |
| 直角 | 10 态 | 106 态 | 1.00 / 1.00 | 否 | 1 | 是 | +0.06 m |
| U 形 | 10 态 | 102 态 | 1.00 / 1.00 | 否 | 1 | 是 | +0.04 m |

结论：
1. 复核网格未发现生产网格漏掉的任何不可行状态（`discretisation_risk = False`）。
2. 可行集在所有场景中都是**单一前缀区间** [0, λ\*]（单调），不存在"可行—不可行—又可行"的非单调岛；因此用首个不可行状态截断是安全的。
3. **但裕度很薄**：S 形 +0.01 m、U 形 +0.04 m、直角 +0.06 m，仅相当于 0.04–0.24 个栅格。
   这意味着生产步长 0.25 cell 在这一量级上**并不具备严格证明力**，只是"未发现反例"。
   若要严格化，后续应把线段采样步长降到 ≤0.05 cell（代价约 5× 校验时间，本阶段已用复核脚本验证可行）。

### 审计 B：地图边界 / valid_mask / 连续距离场一致性

| 场景 | blocked≟(D≤thr \| ¬mask) | is_free≟(D>thr) | 旧栅格判定 vs 连续判定差异 | 出界点被判自由 | 边界全阻塞 | 自由格中心被判自由 | 结论 |
|---|---|---|---|---|---|---|---|
| 5 个合成场景 | 0 | 0 | 0.175 %–0.325 % | 0 | 是 | 0 | 通过 |
| 2 个真实地图裁剪 | 0 | 0 | **6.45 %–9.85 %** | 0 | 否（内部裁剪） | 0 | 通过 |

* 场景内的 `blocked`、`valid_mask`、`dist_m` 三者定义完全自洽（0 处不一致）。
* **旧实现的隐患已量化**：按"最近栅格中心"判定自由 vs 按连续距离场判定，在真实地图上有 **6.5–9.9 %** 的差异——正是之前"可行中心线被误判碰撞→整条回退 A\*"的根因；现已统一为连续判定。
* **出界点**：`distance()` 现对场景外返回 −1（阻塞）。修复前会把边界值 clamp 成"自由"，导致椭圆/线段可能越出地图；修复后 0 个出界点被判自由。
* 真实裁剪的地图边界不阻塞属正常（裁剪位于原图内部），安全性由"出界即阻塞"保证。

## 第二阶段：性能优化

### Profiling（`reports_v2_1/profiling.json`）

| 项 | 优化前 | 说明 |
|---|---|---|
| 116 m 路径单次中心线 | **156 s** | SLSQP 300 迭代 × 3 初值 |
| 其中 `scene.distance` | 4.54 s / 4.71 s（wall 场景） | **76 380 次调用**：目标函数 + 4 个约束块对同一个 x 各算一次 |
| 目标/雅可比/约束/多初值/同伦 | — | 同伦 17–23 ms（可忽略）；雅可比曾用 Python 逐行循环构造稠密矩阵 |
| 单椭圆（分析，未改算法） | **68–71 ms/锚点** | 半空间 7.3 + 一次 max-det 23.0 + 一次精确验证 0.4，其余为外层轮次重复 |

### 采取的优化（均可回退，语义不变）

1. **字段缓存** `_FieldCache`：同一个 x 下 D 与 ∇D 只算一次（目标 + 3 个约束共享）→ 去掉约 5–10 倍重复。
2. **合并约束块**：节点净空与线段配点净空合并为一个不等式块，减少 scipy 调用层数。
3. **雅可比全向量化**：4 个约束的稠密雅可比由 Python 逐行赋值改为索引批量写入。
4. **多分辨率**：站位 > `max_optimised_stations=32` 时在抽稀结点上求解，再把偏移按归一化弧长插值回全部站位，然后投影 + 完整校验。
5. **迭代/初值预算**：由扫描实验确定 `max_iter 200`、`multi_start 1`。

### 预算扫描（`reports_v2_1/effort_sweep.json`，两个最难场景）

| 结点/配点/迭代/初值 | 一侧靠墙 质量保持 | 耗时 | S 形 质量保持 | 耗时 |
|---|---|---|---|---|
| 32 / 2 / 600 / 3（基线） | 100.0 % / 100.0 % | 4740 ms | 100.0 % / 100.0 % | 16597 ms |
| **32 / 2 / 200 / 1（采用）** | **100.0 % / 100.0 %** | **801 ms** | 97.9 % / 87.4 % | **1556 ms** |
| 24 / 2 / 200 / 1 | 100.7 % / 100.3 % | 1712 ms | 79.3 % / 74.1 % | 1862 ms |
| 24 / 1 / 200 / 1 | 100.7 % / 100.3 % | 1646 ms | 110.3 % / 113.3 % | 1552 ms |
| 20 / 1 / 150 / 1 | 99.8 % / 100.0 % | 1167 ms | 57.5 % / 60.4 % | 1252 ms |
| 16 / 1 / 150 / 1 | 99.6 % / 100.3 % | 1206 ms | 17.4 % / 26.5 % | 1233 ms |

**结论**：质量对迭代数不敏感（100 与 600 迭代结果完全一致），耗时随 `初值数 × 迭代数` 近似线性。
采用配置在一侧靠墙场景 **6× 提速且质量零损失**；结点数继续下降会让长路径的插值/修复损失急剧变大，故保持 32。

### 优化后实测

| 场景 | 优化前 | 优化后 |
|---|---|---|
| 一侧靠墙 | 4305 ms | **883 ms** |
| 窄通道 | 334 ms | **3 ms** |
| S 形 | 156 476 ms | **1616 ms** |
| 直角 | 57 804 ms | **260 ms** |
| U 形 | 9157 ms | **1761 ms** |

中位数 ≈ **0.88 s/路径**（目标 ≤1 s：3/5 场景达标）；两条 100 m 以上长路径 1.6–1.8 s，仍未达标。
剩余瓶颈是 SLSQP 每轮 ~4 ms 的固定开销 × 200 迭代；下一步应换"热启动 + 投影/对偶梯度"求解器，而不是继续降结点。

椭圆 55–183 ms/锚点仍高于 20 ms 目标，**按指示未改椭圆算法**，仅记录分解。
